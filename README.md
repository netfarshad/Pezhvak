# Pezhvak
افزونه تبدیل وردپرس به مسنجر و پیامرسان، احراز هویت پیامکی، ارسال فایل، ویس، فیلم و قابلیت‌های دیگر مشابه تلگرام. 
در نسخه‌های ابتدایی این برنامه با نام پیامرسان ساده نصب می‌شه ولی در نسخه‌های بعدی نام اون به پژواک تغییر پیدا می‌کنه.
1. از طریق ریپازیتوری فایل زیپ آخرین نسخه و دانلود کنید و اون روی وردپرس نصب کنید.
2. پس از نصب شورتکد برنامه رو توی یکی از صفحات قرار بدین. ترجیا یک سابدامنه ایجاد کنید با نام web.example.com و توی اون یک وردپرس بیارید بالا و شورتکد رو توی صفحه اصلی اون قرار بدید. بقیه قسمت‌های نسخه وب رو هم کلا ببندید.
